# Governance Framework

## Purpose
This document establishes the project governance structure, decision lifecycles, change management rules, and risk registers for the Sharan Fincorp (Moneyball) repository.

## Scope
Applies to all project operations, database/code revisions, release gates, architectural decisions, and AI assistance boundaries.

## Responsibilities
- **Chief Enterprise Governance Architect**: Coordinates governance reviews, maintains decision registries, and resolves policy exceptions.
- **Project Stakeholders**: Review release readiness and audit RLS/compliance logs.
