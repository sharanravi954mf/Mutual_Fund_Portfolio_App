# Engineering Handbook

## Purpose
This handbook establishes the software engineering guidelines, coding patterns, testing frameworks, and release checklists for developers and AI agents working on the Sharan Fincorp (Moneyball) repository.

## Scope
Covers Dart/Flutter programming, Postgres database migrations, RLS security policies, API gateways, git branch configurations, and code review criteria.

## Responsibilities
- **Lead Developer / Architect**: Maintains the handbook, reviews PRs for compliance, and updates templates.
- **Developer / AI Agent**: Adheres strictly to the guidelines and passes all verification checks before submitting PRs.
