# Documentation Audit & Certification

## Purpose
This directory houses the certification reviews, quality audits, and outstanding debt logs for the Sharan Fincorp (Moneyball) documentation platform.

## Scope
Includes checks on relative links, cross-references, template hierarchies, and standards consistency across all documentation libraries.

---

## Directory Index

- 📋 **[Certification Report](documentation-certification-report.md)**: Main audit findings, quality ratings, and system certification status.
- 🗃️ **[Documentation Debt Register](documentation-debt-register.md)**: Living register of minor inconsistencies, legacy warnings, or path fixes identified during audits.
