# Product Documentation Directory

Welcome to the Product Documentation library for the Sharan Fincorp (Moneyball) platform. This directory outlines what the platform does, why it exists, who uses it, and how the various business entities interact.

---

## Directory Index

- 🎯 **[Product Vision](product-vision.md)**: Mission, vision, core problem statement, business goals, and success metrics.
- 👥 **[User Personas](personas.md)**: Profiles of target users (Investor, Advisor, Administrator, Operations) and future roles.
- 🧱 **[Domain Model](domain-model.md)**: Business objects (Folios, Schemes, Transactions, Holdings) and their conceptual relationships.
- ⚙️ **[Business Capabilities](business-capabilities.md)**: Core modules (Portfolio tracking, Ingestion engine, Invoice overlays, Analytics).
- 🗺️ **[User Journeys](user-journeys.md)**: Step-by-step business flows (Onboarding, Statement upload, Folio claiming, Advisor review).
- 📖 **[Glossary](glossary.md)**: Definition of important terms (XIRR, AMC, NAV, RTA, Folio, Mailback).
- 🗃️ **[Feature Catalog](feature-catalog.md)**: Comprehensive inventory of implemented, in-progress, and planned product capabilities.
- 📋 **[Non-Functional Requirements (NFR)](non-functional-requirements.md)**: Target boundaries for availability, speed, accessibility, and security compliance.
